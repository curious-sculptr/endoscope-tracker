Endoscope Inspection & Repair Log

A custom desktop web application prototype designed to streamline and digitize incoming/outgoing hardware inspection logs, active maintenance statuses, and serial number repair histories for medical endoscopes.

Project Purpose
I noticed an operational bottleneck in my medical lab regarding how equipment damage and tracking cycles were handled manually. I am building this tool to solve that problem while mapping out my full-stack engineering journey.

Tech Stack & Architecture
* Frontend Structure: Semantic HTML5 (Headers, Sections, Forms, Tables)
* Visual Presentation: Custom responsive CSS (CSS Grid, Flexbox architecture)
* Future Additions: JavaScript programming logic (Month 3-6) and cloud databases (Month 10-12)

Learning Journey
This project is built entirely in public, developed during 12-hour weekly study blocks alongside full-time work and single motherhood.
